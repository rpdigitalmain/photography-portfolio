# Security

## Supported versions

This repository does not currently publish versioned releases. Security fixes are applied to the latest code on the default branch.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/rpdigitalmain/photography-portfolio-helena-duarte/security/advisories/new), when available. Do not open a public issue for an undisclosed vulnerability.

Include as much of the following as you can:

- A concise description of the issue and its potential impact.
- The affected page, component, dependency, or configuration.
- Reproduction steps or a minimal proof of concept.
- The browser, operating system, and project version or commit, where relevant.

Avoid including real credentials, private user data, or other secrets in a report. Please allow the maintainers time to investigate and coordinate any public disclosure.

If private vulnerability reporting is unavailable, contact the repository maintainers through GitHub before sharing details publicly.

## Scope

Reports may cover the application source, its dependencies, or build and deployment configuration.

The contact form currently performs client-side validation only; it is not connected to an email delivery service.
