# ADR-0002: Everyday AI Use and Reference-Oriented Design

- **Status:** Accepted
- **Date:** 2026-11-17

## Context

This project is not intended to be a premium product or a higher-tier commercial offering. Its goal is to build something useful as a reference for future projects. A fully bespoke visual design is therefore not a requirement.

AI is used as a regular part of the project workflow.

## Decision

Use AI as an ordinary tool while developing the project. Prioritize a coherent, useful implementation that can be referenced and learned from; do not require every design choice to be fully original or to meet the expectations of a premium product.

## Consequences

- AI-assisted work and conventional implementation work may both inform the project.
- The design can favor clear, established patterns when they serve the reference goal.
- AI-generated suggestions still need review for correctness, consistency, and fit with the project.
